# Review supplementary edition evidence

The edition packs keep the exact target verse, published tags, inferred lookup and source-occurrence links separately. The original raw eBible archives and CrossWire KJV OSIS remain in each applicable pack’s `upstream/` directory. Every archive has a fixed SHA-256 in the audit inputs. The Julia Smith recovery snapshot lives in its pack’s `sources/` directory.

Use Python 3.10 or newer and the app’s installed Node dependencies. Provide a SQLite library generated at the v0.5.0 migration reference. The script checks for its 348,742 Berean and 2,051 KJV reviewed spans before accepting it.

```sh
python3 data-pipeline/edition-evidence/build.py /path/to/v0.5.0/bible.sqlite
python3 data-pipeline/edition-evidence/explain.py /path/to/v0.5.0/bible.sqlite WEB Gen 1 1
python3 data-pipeline/edition-evidence/explain.py /path/to/v0.5.0/bible.sqlite ASV John 11 35
python3 data-pipeline/edition-evidence/verify.py /path/to/v0.5.0/bible.sqlite data-pipeline/sources/edition-evidence
```

To regenerate one edition, append its edition ID to the build command. To compare a separate build without changing the active staging area, supply `--staging /path/to/empty-directory`. The audit first uses the cached input or the edition repo’s preserved copy. If it has to download an input, the content must match the pinned digest. The verification script also reads the shared Robinson printed-order archives from `data-pipeline/sources/` generated by the app’s database build.

Generated book files are JSON Lines. Each record gives UTF-16 text offsets into the native target verse. A `published` row records a distributor’s lexical tag after agreement with an independent aligned English rendering and a unique Strong’s occurrence in the mapped source verse. Repeated English, variant wording and ambiguous references remain available for inspection in the raw archive. Running `explain.py` reports the exact discriminator for each WEB or ASV candidate, including the compared publisher rows and source positions. Each edition’s `inventory.json` lists candidate sources, rights, revision identifiers, per-book decisions and outstanding gaps.

For KJV, CrossWire’s direct KJV2003 English-to-Stephanus indices supply the location. The importer checks the English verse, every indexed Greek spelling against the correctly ordered Scrivener verse, the occurrence position, the Strong’s ID and the saved KJV token boundaries. It preserves existing nonmatching lexical tags and migrated source spans. A directly supported new occurrence can supply a missing tag at its end token. Several English words may share a single source form. The reader preserves the phrase and offers that form alongside it. Only explicitly reviewed standalone cases may replace a word. The two inflections of G264 in 1 John 2:1 have different indices and spellings.

In John 11:35 the WEB and ASV distributor tags, Berean row 92072, CrossWire’s KJV source index and the named Greek readings agree on the verb. The evidence names a witness for each edition and records the reviewed correspondence. English similarity alone has no role in enabling additional restorations. Wycliffe’s immediate source is Latin. Its Hebrew and Greek parallel vocabulary can only support study until a documented correspondence is reviewed.
